Search options

Overall compares the block's colour as seen from a distance. Main colour also finds blocks where your colour is a big part, such as red bricks with grey mortar.

Higher values rank plain, even textures above busy, speckled ones.

Also include

Some mods (GregTech materials, Extra Trees woods) store their textures in grey and colour them in game, so in this list they look grey.

Mods

How it works

  1. Pick a colour with the colour box, type a hex code like #8a6f4d, or use the eyedropper to take one from your screen.
  2. Browse the matches. The best match comes first. The bar under each block shows its main colours and how much of the texture each one covers.
  3. Click a block to search for blocks that look like it. This is handy for building gradients and palettes.

Match quality

How close a block is to your colour:

  • Near-identical hard to tell apart
  • Very close differs only side by side
  • Close noticeable but similar
  • Similar same family of colour
  • Loose nearest available, but a different shade

Good to know

  • Each face of a block is listed on its own, so the top and side of a log are separate results.
  • Names are read from the mods' language files where possible; some are guessed from file names.
  • Machines, pipes, fluids and plants are filtered out. If something wrong slipped through, use Report on that block.
  • Your settings are kept in the page address, so you can share a link to your search.
